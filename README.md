# AdvancedLightsabers

This is a 1.21.1 Fabric port of the [Advanced Lightsabers mod by FiskFille](https://github.com/FiskFille/AdvancedLightsabers) - https://www.curseforge.com/minecraft/mc-mods/advanced-lightsabers!

The old mod only supported Forge 1.7.10 and was last updated 6 years ago (as of the making of this description), and this aims to bring it back so other people can use it!

## Features

**Force Powers**

Use special Holocrons in the structures that generate in the world to access a Force Power GUI, where you can unlock abilities such as:

- Heal
- Speed
- Drain Life
- Force Push
- Blade Throw
- Fortify

and more! You can check out what the abilities do and the upgrades with them in game!

**Structures**

There are new structures, including the Jedi Temples and the Sith Tombs. The sith tombs house the remanents of the Sith Ghosts, which guard access to hidden loot and a chance to find a Sith Holocron.

These structures also have the Light Forcestone and Dark Forcestone for making forges!

**Lightsabers**

Using lightsaber forges, you can create customizable lightsabers! You can have a combination of 4 lightsaber parts to create a lightsaber in the forge, along with 18 unique lightsaber colors. You can also add additional modifications using special crystals to get unique views! Paired with the ability to make double lightsabers, this allows for nearly unlimited customizability, so you can make the lightsaber you always dreamed of!

You can also use the Disassembly Station to break apart lightsabers into their components by powering it with redstone as the fuel. 

**Animations**

There are special animations for double lightsabers and normal lightsabers, as well as configuration for if they're enabled or not! There are also sounds that play when you attack with them.

This has all of the features from the original mod, along with some other useful tools such as a config screen.
